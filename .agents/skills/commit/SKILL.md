Commit the recent changes following these rules:
- Follow the pattern already used in the project;
- Use conventional commits.
- Don't create a body.
- Use english.
- Never commit TODO.txt.
- If necessary, create more than one commit.

## Examples

feat(web): add individual row loader and smooth scroll to document table
chore: add backups folder to .gitignore
refactor(ui): standardize button
refactor: switch traditional functions do arrow functions
